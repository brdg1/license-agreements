(Developer – creates bots, scripts, tools, integrations)

## 1. Introduction

This Agreement applies to **Developers** contributing software, code, scripts, or technical solutions (**Code**) to the **Bridge-Community** and the project **brdg™**.

## 2. Definition of Code

**“Code”** includes:
- **Discord bots**
- **Automation scripts**
- **APIs or integrations**
- **Custom tools**
- **Configuration files**
- **Plugins or modules**
- **Server-side logic or utilities**

## 3. Developer Responsibility

The Developer confirms that:
- They wrote the Code themselves, or
- They have the **rights to contribute it**
- The Code contains **no malicious, harmful, or unauthorized elements**

The Developer grants the Community a **worldwide, perpetual, royalty-free, transferable, non-exclusive license** to:
- **Host and run** the Code
- **Modify or extend** the Code

- **Distribute** compiled versions (if applicable)

Open-source components must retain their **original licenses**.

## 5. Liability

Developers contribute voluntarily and are **not liable** for damage unless caused intentionally or by **gross negligence**.

## 6. Confidentiality

Any private server data accessed for development must remain **confidential**.

## 7. Compensation

Unless explicitly stated, Developer contributions are **unpaid**.

## 8. Acceptance

The Developer accepts the Agreement by posting:

**“I accept the Community Developer Contributor Agreement, Version 1.0.”**
