# COMMUNITY BUILDER / SERVER SETUP CONTRIBUTOR AGREEMENT
(Builder – creates channels, structures, permissions, templates)

Version 1.0

## 1. Scope

This Agreement applies to **Builders** who contribute to the **structural setup** of the **Bridge-Community** server and its project **brdg™**.

## 2. Definition of Contributions

**“Contributions”** include:
- **Channel structures**
- **Permission systems**
- **Category layouts**
- **Automation flows**
- **Server templates**
- **Organizational designs**
- **Event structures**
- **Role systems**

## 3. License Grant

Builders grant the Community a **perpetual, worldwide, royalty-free, non-exclusive license** to:
- **Use** the created server structure
- **Modify** it at any time
- **Reuse** it in future servers
- **Apply** it across partner projects

## 4. Confidentiality

Builders may not leak:
- **Server configurations**
- **Internal structures**
- **Permission layouts**
- **Staff discussions**
- **Unreleased features**

## 5. Compensation

Unless otherwise agreed, contributions are **voluntary and unpaid**.

## 6. Acceptance

Builders accept the Agreement by posting:

**“I accept the Community Builder Contributor Agreement, Version 1.0.”**
